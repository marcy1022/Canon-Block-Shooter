# 02. Game System

## 조작 및 발사
역기획서에서는 화면 드래그를 통해 캐논 각도를 조절하고, 파워를 설정한 뒤 발사하는 방식을 정의합니다. 발사 전 궤도 미리보기를 제공하며, 레벨별 발사 횟수 제한을 둡니다.

## 구조물 파괴
구조물은 항아리, 돌, 기둥 등 서로 다른 내구도와 물리 특성을 가진 오브젝트로 구성합니다. 기둥이나 지지 오브젝트를 파괴하면 상부 오브젝트가 낙하하고, 연쇄 파괴가 발생할 수 있도록 설계합니다.

## 콤보 규칙
STEP 1 구현 완료 보고서에는 0.3초 이내 연속 파괴를 콤보로 판정하는 기준이 기록되어 있습니다.
- 2개 파괴: COMBO! / 1.5x
- 3개 파괴: TRIPLE! / 2.0x
- 4개 이상: SMASH! / 3.0x
- 전체 파괴: TOTAL SMASH! / 5.0x

현재 게임에서 실제 적용되는지는 코드 및 빌드 확인이 필요합니다.

## 클리어 판정 및 물리 안정화
구현 보고서는 파괴 이벤트 직후가 아니라 물리 시뮬레이션이 안정화된 후 클리어 판정을 수행하도록 주의사항을 제시합니다. 이는 오브젝트가 아직 공중에 있는 상태에서 잘못 클리어 처리되는 상황을 방지하기 위한 설계 고려입니다.

## 경제·메타 시스템
역기획서에는 에너지, 코인, 부스터, 레벨 선택 맵, 스타 등급 등의 메타 시스템이 제안되어 있습니다. 이 중 실제 구현 범위는 현재 빌드 기준으로 별도 표기합니다.
