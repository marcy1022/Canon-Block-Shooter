# 06. Contribution & Status

## 본인 기여
제공된 문서로 확인되는 활동은 레퍼런스 역기획, 게임 시스템·레벨·대포 기획, 시장 분석, UI/UX 감사, 개발 단계별 요구사항 및 완료 조건 정리입니다. 실제로 본인이 직접 작성·결정한 범위와 AI가 생성한 초안의 범위를 구분해 최종 표기합니다.

## 프로젝트 상태
- 초기 3D/물리 퍼즐 프로토타입
- 게임 에셋과 비주얼 리소스가 충분하지 않은 상태
- 최종 폴리싱 미완료
- 일부 기획 기능은 구현 완료 여부 확인 필요

## 회고
이 프로젝트를 통해 레퍼런스 게임을 플레이 경험 단위로 분해하고, 핵심 루프와 시스템 요구사항으로 재구성하는 역기획 과정을 경험했습니다. 또한 물리 기반 게임에서는 단순 파괴뿐 아니라 지지 관계, 시뮬레이션 안정화, 클리어 판정 시점 등 플레이 경험과 직결되는 규칙을 명확히 정의해야 한다는 점을 확인했습니다.
