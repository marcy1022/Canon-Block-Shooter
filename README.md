# Canon-Block-Shooter
### 3D 물리 퍼즐 프로토타입 | 역기획·시스템·레벨 기획 포트폴리오

> 캐논 발사와 구조물의 약점 타격, 연쇄 붕괴를 핵심 재미로 삼은 물리 기반 퍼즐 프로토타입입니다.

- **장르:** 물리 기반 퍼즐
- **레퍼런스:** Smash Fest! - Royal Puzzle (제공된 역기획서 기준)
- **엔진:** Unity (문서 간 버전·2D/3D 표기 차이 확인 필요)
- **진행 상태:** 초기 프로토타입 / 에셋 및 폴리싱 미완료
- **기획 기간:** 2026.10~11 문서 기록 기준
- **담당:** 레퍼런스 분석, 게임 규칙·시스템·스테이지·UI/UX 기획 [실제 참여 범위 확인]

## 프로젝트 개요
플레이어가 캐논의 각도와 파워를 조절해 투사체를 발사하고, 구조물의 약점을 맞혀 물리적인 연쇄 붕괴를 유도하는 퍼즐 게임을 기획했습니다.

## 핵심 재미 가설
“약점을 찾아 한 번의 발사로 구조물 전체를 무너뜨리는 카타르시스”

## 주요 기획 내용
- 레퍼런스 게임 플레이 영상과 스토어 정보를 기반으로 한 역기획
- 캐논 조준·발사 및 궤도 미리보기 규칙
- 구조물 지지 관계와 약점 파괴 설계
- 콤보 판정 및 연쇄 붕괴 규칙
- 스테이지·난이도 확장 기획
- 에너지·코인·부스터 등 경제 시스템 초안
- QA 체크포인트 및 UI/UX 감사

## 구현 기록
2026-10-28 STEP 1 구현 완료 보고서에는 파괴 대상 오브젝트, StructureGroup, ComboTracker, TNTExplosion 등의 작업 항목과 캐논·투사체 관련 구현 계획/체크포인트가 기록되어 있습니다. 각 기능의 현재 구현 여부는 저장소의 실제 코드와 플레이 빌드로 확인해야 합니다.
