# 04. UI/UX Audit

## 감사 목적
2026-11-03 UI/UX Audit 문서를 바탕으로, 모바일 세로 화면에서 조작과 정보 인지가 원활한지 점검합니다.

## 주요 점검 영역
- 캐논 조준 중 각도·파워 피드백
- 궤도 미리보기의 가독성
- 남은 발사 횟수 및 목표 정보
- 파괴·콤보 피드백
- 결과 화면에서 별 등급과 보상 정보
- 버튼과 팝업의 크기 및 배치
