# 03. Level Design

## 스테이지 설계 방향
- 구조물 형태와 약점 위치를 단계적으로 학습
- 발사 각도와 파워 조절을 이해시키는 초기 레벨
- 복수 구조물과 지지 관계를 활용하는 중반 레벨
- 움직이는 오브젝트, 제한된 발사 횟수 등으로 변주하는 후반 레벨

## 기획 문서상 확장안
2026-11-04 스테이지 구성 및 2026-10-30 레벨 설계 문서에는 챕터와 스테이지 확장안이 포함되어 있습니다. 문서상 제안된 4개 챕터·60스테이지 등의 수치는 기획 목표이며 실제 구현 수량으로 표현하지 않습니다.

## 레벨 검토 기준
- 핵심 약점이 플레이어에게 읽히는가?
- 정답 경로가 하나뿐인지, 대안적 해결법이 있는가?
- 발사 횟수 제한이 난이도와 맞는가?
- 물리 결과가 예측 가능하면서도 만족스러운가?
- 실패 후 플레이어가 무엇을 학습하는가?
