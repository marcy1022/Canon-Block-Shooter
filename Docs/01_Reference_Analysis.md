# 01. Reference Analysis

## 분석 대상
제공된 역기획서의 분석 대상은 `Smash Fest! - Royal Puzzle`이며, 문서에는 실제 게임플레이 영상 및 스토어 정보를 바탕으로 분석했고 원작 내부 스펙과 다를 수 있다고 명시되어 있습니다.

## 핵심 게임 경험 가설
캐논으로 구조물의 약점을 타격해 연쇄 붕괴를 일으키는 물리 퍼즐입니다. 단순히 오브젝트를 많이 파괴하는 것보다, 구조물의 지지 관계를 이해하고 적은 발사 횟수로 전체를 무너뜨리는 경험을 핵심 재미로 정의했습니다.

## 핵심 루프
1. 구조물과 오브젝트 배치 확인
2. 약점 및 발사 경로 탐색
3. 캐논 각도·파워 조절
4. 발사 및 충돌
5. 물리 연쇄 붕괴
6. 목표 파괴 여부 및 잔여 발사 수에 따른 결과 판정

## 분석의 한계
이 문서는 공개 영상과 스토어 정보를 기반으로 한 외부 관찰 역기획입니다. 원작 개발사의 내부 수치나 실제 구현 방식으로 단정하지 않습니다.

## 포트폴리오 보강
- 레퍼런스 플레이 영상 캡처
- 핵심 루프 도식
- 레벨별 구조물·약점 분석 사례
- 우리 프로토타입에서 채택·변형한 요소 비교
